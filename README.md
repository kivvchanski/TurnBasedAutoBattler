Проект - автобатлер для тестового задания.

Папки:
  ClassBuffs – папка с DT классов и классами навыков.
  Enums – все перечисления для классов, типов урона и тд.
  Models – 3д модели, текстуры и анимации.
  Weapons – определения оружия и их характеристик.
  Widgets – интерфейсные элементы.

TurnSystemManager - класс-менеджер для пошаговых сражений и определения очередности хода. Связан с TurnBasedManager через подписку на событие "TurnPassed"
TurnBasedObject - базвый класс, экземпляры которого могут быть участниками пошагового сражения.
  BP_Fighter – базовый класс бойца (наследуется от TurnBasedObject). Получает возможность использовать способности, реализация атаки и получения урона.
    BP_PlayerFighter – наследник BP_Fighter для персонажа игрока. Имеет возможность повышать уровень, получать способности классов.
    BP_MobFighter – наследник BP_Fighter для неигрового персонажа
BP_BaseAbility – базовый класс активных способностей.
