# Turn-Based Autobattler (UE 5.6)

## Описание проекта
Проект представляет собой **автобатлер**, разработанный на **Unreal Engine 5.6** в рамках тестового задания.  
Основой проекта является система **пошаговых сражений**, в которой каждый участник управляется через общий менеджер ходов и использует способности, определяемые своим классом и вооружением.

---

## Структура проекта

**Основные файлы и папки находятся по пути:**  
`Content/Game`

| Папка | Назначение |
|:------|:------------|
| **ClassBuffs** | Папка с Data Tables классов и классами навыков. |
| **Enums** | Все перечисления для классов, типов урона, состояний и т.п. |
| **Models** | 3D-модели, текстуры и анимации персонажей. |
| **Weapons** | Определения оружия и их характеристик. |
| **Widgets** | Интерфейсные элементы (HUD, панели способностей и т.д.). |

## Основные классы

### **TurnSystemManager**
Класс-менеджер, управляющий ходами участников боя.  
Отвечает за определение очередности и передачу хода активным объектам.  
Связан с `TurnBasedObject` через подписку на событие **`TurnPassed`**.

**Основные задачи:**
- Управление циклом боя;
- Регистрация участников пошаговой системы;
- Отправка событий о смене активного бойца.

---

### **TurnBasedObject**
Базовый класс, экземпляры которого могут быть участниками пошагового сражения.

**Основные функции:**
- Методы для начала и завершения хода (MakeTurn и PassTurn);

---

### **BP_Fighter**
Базовый класс бойца (наследуется от `TurnBasedObject`).  
Реализует базовую боевую логику — атаку, получение урона, применение способностей.

**Ключевые возможности:**
- Использование способностей (`BP_BaseAbility`);
- Разделение умений на атакующие и защитные;
- Обработка попаданий и эффектов урона.

---

### **BP_PlayerFighter**
Наследник `BP_Fighter`, представляющий персонажа игрока.  
Добавляет механику прокачки и систему классовых способностей.

**Особенности:**
- Повышение уровня;
- Получение способностей в зависимости от выбранного класса;
- Синхронизация с таблицами `DT_Classes`, `DT_WarriorPerks`, `DT_RoguePerks`, `DT_BarbarianPerks`.

---

### **BP_MobFighter**
Наследник `BP_Fighter` для неигровых персонажей.  
Реализует базовое поведение противников и выбор действий через простую систему ИИ.

---

### **BP_BaseAbility**
Базовый класс активных способностей.  
От него наследуются все умения, используемые бойцами.

**Примеры наследников:**
- `BP_DragonFlame`
- `BP_PoisonAttack`
- `BP_Shield`
- `BP_Rage`
- `BP_StoneSkin`
- и другие...

Каждая способность может быть активирована либо при атаке, либо при получении урона. Также возможны добавления дополнительных условий активации способностей.

## Data Tables

| Таблица | Назначение |
|:---------|:------------|
| **DT_Mobs** | Информация о неигровых противниках. |
| **DT_Classes** | Общая информация о классах игрока. |
| **DT_WarriorPerks** / **DT_RoguePerks** / **DT_BarbarianPerks** | Бонусы и способности, получаемые при повышении уровня. |
| **DT_Weapons** | Информация обо всём оружии, его характеристиках и типах урона. |
